# claude-view

Скрипты, которыми AI-агент смотрел на страницу: он не видит браузер, поэтому снимал
её через Playwright и разглядывал скриншоты. К решению задачи отношения не имеют,
в бандл не попадают, запускать для работы приложения не нужно.

Ими искали положение модели на этапе совмещения — см. [docs/choose.md](../../docs/choose.md), п. 11.

| Скрипт             | Что делает                                                                                                   |
| ------------------ | ------------------------------------------------------------------------------------------------------------ |
| `screenshot.mjs`   | снимает страницу в четырёх геометриях окна: широкий и узкий десктоп, телефон в двух ориентациях              |
| `shot.mjs`         | один снимок, при желании — вырезом: `node scripts/claude-view/shot.mjs <url> <файл> [x,y,w,h]`               |
| `grid.mjs`         | снимок с координатной сеткой в пикселях исходного кадра — по ней снимаются отметки для `npm run triangulate` |
| `adjust.mjs`       | жмёт кнопки отладочной панели (`?debug`) и снимает результат                                                 |
| `try-position.mjs` | временно подставляет координаты модели в конфиг, снимает кадр и возвращает конфиг на место                   |

Всем нужен запущенный dev-сервер (`npm run dev`) и его адрес в аргументах.
Снимки складываются в `screenshots/`, папка в `.gitignore`.

Инструменты, которые остались в `scripts/`, — часть решения, а не отладки агента:
`verify-projection.ts`, `triangulate.ts`, `solve-position.ts` (`npm run verify`, `triangulate`, `solve`).
